# CoffeeTimer 取扱説明書

最終更新：2026-09-30（第1版）

---

## 1. はじめに

### 1.1 何ができるアプリか

CoffeeTimer は、コーヒーを淹れるときに、手順どおりに時間と注ぐ量を知らせてくれるタイマーです。

- YouTube のコーヒーのレシピ動画の URL を入れると、AI（Google の Gemini）が動画を見て、豆の量・湯量・湯温・挽き目・手順を読み取ります
- 読み取った内容を確かめて直してから保存し、タイマーで淹れます
- 手順が変わるたびに、音と読み上げで知らせます（例「1投目。120グラムまで注いでください」）
- 豆の量を変えると、湯量と各手順の目標量を計算し直します
- 淹れたあとに、豆の名前・評価・メモを「淹れた記録」として残せます
- レシピをファイルにして、LINE やメールで人に渡せます

### 1.2 開き方

スマホ（iPhone・Android）のブラウザで、次のアドレスを開きます。

**https://kobayashikenpa.github.io/CoffeeTimer/**

- iPhone は Safari、Android は Chrome で開くのがおすすめです
- インターネットにつながっていないと開けません

### 1.3 ホーム画面に追加する

ホーム画面に追加すると、アプリのようにアイコンから開けます。保存したレシピも消えにくくなります（1.4）。

**iPhone（Safari）**

1. このアプリのページを Safari で開きます
2. 画面の下（または上）の共有ボタン（四角から上向きの矢印）を押します
3. 「ホーム画面に追加」を選びます
4. 「追加」を押します

**Android（Chrome）**

1. このアプリのページを Chrome で開きます
2. 右上の「︙」（メニュー）を押します
3. 「ホーム画面に追加」（または「アプリをインストール」）を選びます
4. 「追加」を押します

ホーム画面に「CoffeeTimer」のアイコンが出ます。同じ説明は、アプリの「設定」タブの「ホーム画面に追加する」にもあります。

### 1.4 データの保存場所と注意

- レシピ・淹れた記録・設定・APIキーは、**そのスマホのブラウザの中にだけ** 保存されます。ほかのスマホやパソコンとは共有されません
- アカウントの登録はありません
- **iPhone の Safari は、7日間このページを開かないと、保存したデータを消すことがあります。**「ホーム画面に追加」して使うと消えにくくなります
- 念のため、ときどき「設定」タブの「バックアップを書き出す」でファイルを保存しておいてください（9.3）
- ブラウザの「履歴とデータを消去」などをすると、保存したデータも消えます

## 2. 最初の準備（Gemini の APIキーを取って設定する）

YouTube の動画や文章からレシピを AI で読み取るには、「APIキー」が必要です。
APIキーは、Google の AI（Gemini）を使うための **あなた専用の鍵となる文字列** です。Google のアカウントがあれば無料で取れます。

> APIキーが無くても、レシピを手で入れる・人から受け取ったファイルを読み込む・タイマーで淹れる、はできます。AI で読み取るときだけ必要です。

### 2.1 APIキーを取る（Google AI Studio）

Google の「Google AI Studio」というサイトでキーを作ります。Google の画面は、ときどきボタンの名前や場所が少し変わります。下の手順と同じ言葉が見つからないときは、近い意味のボタンを探してください。

1. アプリの「設定」タブを開きます
2. 「APIキー（AI の読み取り）」の欄の「APIキーの取り方」を押して開きます
3. 「Google AI Studio（APIキーの画面）↗」のボタンを押します（別の画面で開きます）。
   直接開くときは **https://aistudio.google.com/** です
4. Google のアカウントでログインします（Gmail などで使っているアカウントで構いません）
5. 初めてのときは、利用規約などへの同意を求められることがあります。内容を読んで同意します
6. 「API キー」「Get API key」などと書かれた場所を開きます（画面の左側のメニューや、右上にあることが多いです）
7. 「APIキーを作成」「Create API key」などと書かれたボタンを押します
8. 「プロジェクト」を選ぶように言われたら、出てきたもの（または新しく作るもの）を選んで進めます。どれを選んでもこのアプリでは同じように使えます
9. 英数字が長く並んだ文字列（APIキー）が出ます。横のコピーのボタン（または「コピー」）を押してコピーします

### 2.2 アプリに APIキーを入れる

1. CoffeeTimer に戻り、「設定」タブを開きます
2. 「APIキー（AI の読み取り）」の欄の「APIキー」の入力欄を押します
3. コピーしたキーを貼り付けます（入れた文字は「●」で隠れて表示されます）
4. 「保存」を押します
5. 「今の状態：**設定済み**」になったことを確かめます
6. 使えるかを試すため、「キーを確かめる」を押します
7. 「✓ このキーは使えます」と出れば準備は完了です

「⚠ APIキーが正しくないようです。キーを入れ直してください」と出たときは、コピーのときに余分な文字が入ったり、一部が欠けたりしていないかを確かめ、「キーを入れ直す」から入れ直してください。

### 2.3 キーを入れ直す・消す

- **入れ直す**：「キーを入れ直す」を押し、「新しい APIキー」の欄に貼り付けて「保存」を押します（やめるときは「やめる」）
- **消す**：「キーを消す」を押し、確認で「消す」を押します。消すと AI で読み取れなくなります

### 2.4 APIキーについての大事な注意

- **APIキーは、ほかの人に教えないでください。** キーを知っている人は、あなたの名前で AI を使えてしまいます。LINE やメールで送ったり、画面の写真を人に見せたりしないでください
- **無料で使える回数には上限があります。** 続けて何度も読み取ると「AI の利用回数の上限に達しました」と出ることがあります。しばらく（数分〜1日）待つと、また使えるようになります
- **キーはそのスマホのブラウザの中にだけ保存されます。** 画面には「設定済み」とだけ出て、キーの文字は出ません。バックアップや人に渡すファイルにも入りません。スマホを替えたときや、別のスマホで使うときは、そのスマホでもう一度キーを入れてください（同じキーをもう一度コピーして使えます。キーは Google AI Studio でいつでも見られます）
- もしキーを人に知られてしまったときは、Google AI Studio でそのキーを消し（削除し）、新しいキーを作ってアプリに入れ直してください

## 3. 画面の見方

画面の下に3つのタブがあります。押すと切り替わります。

| タブ | 中身 |
|---|---|
| ☕ レシピ | レシピ一覧。レシピの追加・確認・編集と、タイマー |
| ✎ 記録 | 淹れた記録の一覧 |
| ⚙ 設定 | APIキー、音と読み上げ、バックアップ、ホーム画面への追加、データの保存について |

- タイマー画面の間は、画面を広く使うため下のタブが隠れます。「← 一覧」で一覧に戻るとタブが出ます

### 3.1 レシピ一覧

「レシピ」タブを開くと、保存したレシピが並びます。

- お気に入り（★）のレシピが上に並び、その中では新しく追加・直したものが上です
- 1件ごとに、レシピ名・器具・豆の量・湯量・比率・抽出時間が出ます
- レシピ名のところを押すと、タイマー画面が開きます
- 右の「☆」でお気に入り（8章）、「⋯」で「編集」「人に渡す」「削除」が出ます
- 最初はレシピが0件です。「＋ レシピを追加」から作ります

## 4. YouTube の動画からレシピを作る

「＋ レシピを追加」を押すと「レシピを追加」の画面が開き、入れ方を選べます。

| 入れ方 | 使うとき |
|---|---|
| YouTube の URL | 動画から AI が読み取ります（基本） |
| 文章を貼り付ける | 説明欄やブログの文章から AI が読み取ります（動画でうまくいかないとき） |
| ファイルから受け取る | 人から渡されたレシピのファイルを読み込みます（9.2） |
| 手で入れる | 空の画面から自分で入れます（4.4） |

AI で読み取るには APIキーが必要です（2章）。

### 4.1 動画の URL をコピーする

YouTube のアプリで、読み取りたいレシピの動画を開きます。

1. 動画の下の「共有」を押します
2. 「コピー」（または「リンクをコピー」）を押します

### 4.2 URL から読み取る

1. CoffeeTimer の「レシピ」タブで「＋ レシピを追加」を押します
2. 「YouTube の URL」を選びます
3. 「YouTube の動画の URL」の欄を押し、コピーした URL を貼り付けます
4. 「AI で読み取る」を押します
5. 「動画を読み取っています（1〜2分かかることがあります）」と出るので、そのまま待ちます（経過の時間も出ます）
6. 読み取れると、確認・編集画面が開きます。5章に進んで、中身を確かめてから保存します

- 読み取りをやめるときは「やめる」を押します
- 英語など日本語以外の動画も読み取れます。手順名・説明は日本語に訳して入ります
- 「oz」「℉」などで出てくる量・温度は g・℃ に直して入ります
- 動画にはっきり出てこない値は空のままになります。確認・編集画面で入れてください
- 受け付ける URL は、`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/shorts/…`、`m.youtube.com/…` の形です。違う形のときは、送る前に「YouTube の動画の URL を入れてください（例 https://www.youtube.com/watch?v=… 、https://youtu.be/…）」と出ます

### 4.3 うまくいかないとき：説明欄を貼り付ける

動画が読めないときは、動画の説明欄やブログに書かれたレシピの文章から読み取れます。

1. YouTube のアプリで動画の説明欄を開き、豆の量・湯量・手順が書かれたところを長押ししてコピーします（全部をコピーしても構いません）
2. 「レシピを追加」の画面で「文章を貼り付ける」を選びます
   （「この動画は読み取れませんでした…」などと出たときは、その下の「文章を貼り付ける」を押しても切り替わります。入れていた URL は「動画の URL（あれば）」に移ります）
3. 「レシピの文章」の欄に貼り付けます
4. 動画の URL があれば「動画の URL（あれば）」の欄に入れます。入れると、レシピの「動画の URL」として保存され、あとで「動画を開く」から動画を見られます（AI には送りません）
5. 「AI で読み取る」を押します
6. 「文章を読み取っています（1〜2分かかることがあります）」と出るので待ちます
7. 読み取れると確認・編集画面が開きます（5章）

### 4.4 手で入れる

AI を使わずに、自分でレシピを作ることもできます。

1. 「＋ レシピを追加」を押します
2. 「手で入れる」を押します
3. 空の「レシピを作る」画面が開きます。5章と同じように入れて「保存」を押します

## 5. レシピを確かめて直す

AI で読み取った直後と、一覧の「⋯」→「編集」（またはタイマー画面の「編集」）から開く画面です。新しいレシピのときは見出しが「レシピを作る」、保存したレシピを開いたときは「レシピを直す」になります。

### 5.1 AI で読み取った直後に確かめる

画面の上に「**AI の読み取りは間違えることがあります。動画と見比べて確かめてください**」と出ます。

1. 「動画を開く ↗」を押すと、YouTube が別の画面で開きます
2. 動画と見比べて、豆の量・湯量・手順の時刻・目標量が合っているかを確かめます
3. 違うところを直します
4. 赤い字が出ているところは、入れないと保存できない項目です。入れてください

### 5.2 基本の情報

| 項目 | 入れること |
|---|---|
| レシピ名（必須） | 例 4:6メソッド |
| 豆の量（必須） | g。小数第1位まで（例 15、15.5） |
| 湯量（必須） | g。整数（例 250） |
| 比率（豆:湯） | 豆の量と湯量から自動で出ます（例 1:16.7） |
| 湯温 | ℃。整数（例 92） |
| 挽き目 | 極細挽き／細挽き／中細挽き／中挽き／粗挽き／未設定 から選びます |
| 完成時刻（必須） | 抽出が終わる時刻。「分:秒」（例 3:00）か秒（例 180）で入れます |
| 器具 | 例 V60、エアロプレス |
| 作者 | 例 動画のチャンネル名 |
| 動画の URL | YouTube の URL。入れると「動画を開く」が使えます |
| 説明 | ひと言の説明（例 すっきりした味になる淹れ方） |

- 重さはすべて **g** です（湯量も ml ではなく g）

### 5.3 手順

手順は、タイマーで順に進む1つ1つの作業です（例 蒸らし、1投目）。

| 項目 | 入れること |
|---|---|
| 開始（必須） | その手順が始まる時刻。最初の手順は 0:00。「分:秒」か秒で入れます |
| 目標量 | その手順の終わりに、スケール（はかり）が示す重さ（注いだ合計）。お湯を注がない手順（待つ、プレスする など）は空にします |
| 手順名（必須） | 例 蒸らし、2投目 |
| 説明 | 例 中心から「の」の字を描くように注ぐ |
| 注意の手順にする | オンにすると、タイマーで赤く出し、低めの音で知らせます。「注意の文」（例 ゆっくり押す）も入れられます |

- 目標量を入れると「この手順で注ぐ量 +60g」のように、その手順で注ぐ量が出ます
- **手順を増やす**：いちばん下の「＋ 手順を追加」を押します
- **手順を消す**：その手順の「この手順を削除」を押します
- **並べ替え**：開始の時刻の順に自動で並びます。時刻を直すと並び直します

### 5.4 保存する

1. いちばん下の「保存」を押します
2. 一覧に戻り、レシピが入ります

保存できないとき（赤い字）：

- 「保存できません。赤い字のところ（◯ か所）を直してください。」と出て、直すところに動きます
- たとえば：レシピ名・豆の量・湯量・完成時刻・手順名が空、最初の手順の開始が 0:00 でない、開始の時刻が前の手順より後になっていない、完成時刻が最後の手順の開始より後になっていない

保存はできるが、確かめてほしいとき（⚠）：

- 「⚠ 確かめてください（このままでも保存できます）」と出ます
- 目標量が前の目標量より小さいとき
- 最後の目標量が湯量と違うとき（エアロプレスのように、あとから割り水をするレシピなら、そのままで構いません）

### 5.5 保存せずに戻る

「やめる」を押します。直したところがあるときは「入れた内容を保存せずに戻りますか？」と聞かれます。

- 「保存せずに戻る」：直したところを捨てて戻ります
- 「編集を続ける」：画面に戻ります

### 5.6 レシピを消す

1. 一覧で、そのレシピの「⋯」を押します
2. 「削除」を押します
3. 「削除する」を押します

消したレシピは元に戻せません。そのレシピで淹れた記録は消えずに残ります。

## 6. タイマーで淹れる

一覧でレシピ名を押すと、タイマー画面が開きます。

### 6.1 画面の見方

- 上：「← 一覧」（一覧に戻る）、レシピ名、「動画を開く ↗」（動画の URL があるとき）、「編集」
- 豆の量・湯量・比率・抽出時間・湯温・挽き目
- 「音」「読み上げ」の切り替え（6.5）
- まん中の輪：経過時間（大きな数字）と、進み具合。輪の上の目印は手順の切り替わりです。輪の中に、今の状態（準備／抽出中／一時停止／完成）が出ます
- 今の手順：手順名、**目標量（いちばん大きな字。例「120g まで」）**、注ぐ量（例「+60g」）、説明、注意（赤）
  - 始める前は「最初の手順（START で始まります）」と出ます
- 次の手順：「次：◯◯」と、始まるまでの残り（抽出中は「あと 12 秒」、始める前は「0:40 から」）
- 手順の一覧：終わった手順に「✓」、今の手順に「▶」が付きます。各手順の開始の時刻と目標量が出ます
- いちばん下：「START」と「RESET」

### 6.2 淹れる

1. お湯・豆・ドリッパー・スケールを用意します
2. 必要なら豆の量を変えます（6.3）
3. お湯を注ぎ始めるのと同時に「START」を押します
4. 手順が変わるたびに音が鳴り、手順名と目標量が読み上げられます（例「蒸らし。30グラムまで注いでください」）
5. スケールの表示が「今の手順」の目標量になるまで注ぎます
6. 完成時刻になると、音が3回鳴って「抽出完了です」と読み上げられ、「抽出完了」と出ます
7. 記録を残すときは「記録をつける」を押します（7章）

- 抽出中と一時停止中は、スマホの画面が自動で暗くならないようにしています。
  「この端末では、画面を暗くしない機能が使えません。抽出中に画面が暗くなったら、画面に触れてください。」と出たときは、その端末ではこの働きが使えません
- 抽出中にスマホの画面が消えたり、別のアプリに切り替えたりしても、戻ると実際の時間に合わせた表示に戻ります（その間の音・読み上げは鳴らないことがあります）
- 音の種類：普通の手順は短い音1回、注意の手順は低めの音1回、完成は音3回です

### 6.3 豆の量を変える

レシピと違う豆の量で淹れるとき、始める前に豆の量を変えられます。湯量と各手順の目標量が、豆の量に合わせて計算し直されます。**時間は変わりません。**

1. タイマー画面の「豆の量」の「−」「＋」を押します（0.5g ずつ変わります）
   または、数字の欄を押して直接入れます（小数第1位まで）
2. 湯量と、手順の目標量が変わったことを確かめます
   （例：豆 15g・湯量 250g のレシピで豆を 20g にすると、湯量は 333g になります）
3. 「START」を押して淹れます

- 変えた豆の量は、その時だけ使います。レシピ自体は変わりません
- レシピの豆の量に戻すときは「元に戻す」を押します
- 抽出中・一時停止中は変えられません。変えるときは「RESET」で準備に戻します
- 目標量は 1g 単位に四捨五入されます

### 6.4 一時停止・やり直し・手順へ飛ぶ

- **一時停止**：抽出中に「一時停止」を押します。止めていた時間は数えません
- **再開**：「再開」を押すと続きから進みます
- **最初からやり直す**：「RESET」を押します（確認は出ません）。準備の状態に戻ります
- **手順へ飛ぶ**：「手順の一覧」の手順を押すと、その手順の開始の時刻に飛びます
  - 抽出中なら、そこから続けて進みます
  - 一時停止中なら、一時停止のまま位置だけ移ります
  - 始める前なら、その手順からすぐ始まります

### 6.5 音と読み上げ

- タイマー画面の「音」「読み上げ」で、その場でオン・オフを切り替えられます（この画面の中だけの切り替えです）
- タイマーを開いたときの最初の状態は、「設定」タブの「音と読み上げ」で決めます
- **iPhone は、マナーモード（消音。本体の横のスイッチ）のときは音や読み上げが鳴らないことがあります。** 音を聞きたいときはマナーモードを切ってください。Android でも、マナーモードやサイレントのときは鳴らないことがあります
- スマホの音量が小さいと聞こえません。音量ボタンで上げてください

---

## 7. 淹れた記録をつける・見る

実際に淹れたときの豆の名前・評価・メモを残せます。

### 7.1 記録をつける

1. タイマーで完成すると「記録をつける」が出るので押します
2. 「淹れた記録をつける」画面が開きます。レシピ名・豆の量・湯量・比率・日時は自動で入っています（豆の量を変えて淹れたときは、その値が入ります）
3. 「豆の名前・お店」を入れます（例 エチオピア（○○珈琲））
4. 「評価」の ☆ を押して ★1〜5 をつけます（同じ ★ をもう一度押すか、「評価を消す」で評価なしに戻せます）
5. 「メモ」に感想を書きます（例 酸味がやわらか。次は湯温を少し上げる）
6. 「保存」を押します

- 保存すると「記録」タブに移り、「淹れた記録を保存しました」と出ます
- 日時は直せます
- 豆の名前・評価・メモは、どれも入れなくても保存できます
- 保存しないときは「やめる」を押します。入れたところがあるときは「入れた内容を保存せずに戻りますか？」と聞かれます（「保存せずに戻る」／「入力を続ける」）

### 7.2 記録を見る

「記録」タブを押すと「淹れた記録」の一覧が出ます。

- 新しい順に並びます。日時・評価・レシピ名・豆の量・湯量・豆の名前・メモが出ます
- **レシピで絞り込む**：上の「レシピで絞り込む」から、見たいレシピを選びます。「すべてのレシピ」で全部に戻ります
- 消したレシピの記録も残ります。一覧では「（削除したレシピ）」と付きます

### 7.3 記録を直す・消す

1. 「記録」タブで、直したい記録を押します
2. 「記録を直す」画面が開きます
3. 直して「保存」を押します

消すときは「この記録を削除」を押し、確認で「削除する」を押します。消した記録は元に戻せません。

2. 「★」になり、一覧の上に移ります

外すときは、もう一度「★」を押します。

## 9. レシピを人に渡す・受け取る、バックアップ

### 9.1 レシピを人に渡す

レシピを1件ずつファイルにして、LINE やメールで送れます。

1. レシピ一覧で、渡したいレシピの「⋯」を押します
2. 「人に渡す」を押します
3. スマホの共有の画面が開くので、LINE・メールなど送り先を選んで送ります

- 共有の画面が使えないスマホでは、ファイルとしてスマホに保存されます（「スマホの「ファイル」や「ダウンロード」に入っています」と出ます）。そのファイルを LINE やメールに付けて送ってください
- ファイルの名前は「coffeetimer-recipe-（レシピ名）.json」です
- ファイルには、淹れた記録・APIキー・お気に入りの印は入りません

### 9.2 人からレシピを受け取る

1. LINE やメールで受け取ったファイルを、先にスマホに保存します（LINE なら、ファイルを開いて保存・「ファイルに保存」などを選びます）
2. CoffeeTimer の「レシピ」タブで「＋ レシピを追加」を押します
3. 「ファイルから受け取る」を選びます
4. 「ファイルを選ぶ」を押し、保存したファイル（名前が「coffeetimer-recipe-」で始まる .json のファイル）を選びます
5. 確認・編集画面が開き、「人から受け取ったレシピです。中身を確かめてから「保存」を押すと、新しいレシピとして一覧に入ります」と出ます
6. 中身を確かめて「保存」を押します

- 同じファイルを2回読み込むと、同じレシピが2件になります。いらないほうは「⋯」→「削除」で消してください

### 9.3 バックアップを書き出す

スマホを買い替えたときや、データが消えたときに戻せるよう、全部のデータを1つのファイルにしておけます。

1. 「設定」タブを開きます
2. 「バックアップ」の欄の「バックアップを書き出す」を押します
3. スマホの共有の画面が開くので、保存先を選びます（iPhone なら「"ファイル"に保存」、自分宛てのメール、など）

- ファイルの名前は「coffeetimer-backup-（日付）.json」です
- 入るもの：レシピ・淹れた記録・設定（音と読み上げ）
- **APIキーは入りません。** 新しいスマホでは、キーをもう一度入れてください（2章）
- ときどき（たとえば月に1回や、レシピを増やしたとき）書き出しておくと安心です

### 9.4 バックアップを読み込む

1. 「設定」タブを開きます
2. 「バックアップを読み込む」を押します
3. 書き出したバックアップのファイルを選びます
4. 「バックアップを読み込みますか？」と出て、レシピ・淹れた記録それぞれの「足す」「上書き」の件数が出ます
5. 件数を確かめて「読み込む」を押します（同じレシピ・記録があるときは「上書きして読み込む」になります）
6. 「✓ バックアップを読み込みました（レシピ ◯件・淹れた記録 ◯件）」と出れば完了です

- 読み込むと、**今のデータに足します**。今のデータは消えません
- 同じレシピ・記録があるときは、ファイルの内容で上書きします。上書きしたものは元に戻せません
- 音・読み上げの設定も、ファイルのものになります。APIキーは変わりません
- 違うファイルや壊れたファイルのときは、何も変えずにエラーを出します

## 10. 困ったとき（よくある表示と対処）

### 10.1 AI の読み取り

| 表示 | 対処 |
|---|---|
| AI を使うには APIキーの設定が必要です | 「設定を開く」を押し、APIキーを入れます（2章） |
| APIキーが正しくないようです。設定を確かめてください | 「設定を開く」を押し、「キーを入れ直す」から正しいキーを入れ直します。「キーを確かめる」で試せます |
| AI の利用回数の上限に達しました。しばらく待ってから試してください | 無料で使える回数の上限です。しばらく（数分〜1日）待ってから試します |
| この動画は読み取れませんでした。説明欄の文章を貼り付けて試してください | 非公開・削除・年齢制限などの動画は読めません。「文章を貼り付ける」を押して、説明欄の文章から読み取ります（4.3） |
| この動画からコーヒーのレシピを見つけられませんでした | コーヒーのレシピの動画か確かめます。説明欄の文章を貼り付けるか、「手で入れる」で作ります |
| インターネットにつながっていないようです | Wi-Fi やモバイル通信がつながっているかを確かめて、もう一度試します |
| 読み取りに失敗しました。もう一度試すか、文章の貼り付けを試してください | もう一度「AI で読み取る」を押します。続くときは「文章を貼り付ける」で試します。長い時間（3分）かかって止まったときも、この表示になります |
| YouTube の動画の URL を入れてください（例 …） | 入れた URL が YouTube の動画の URL ではありません。YouTube のアプリの「共有」→「コピー」でコピーし直します |
| レシピの文章を貼り付けてください | 「文章を貼り付ける」で、文章の欄が空です |
| URL の形が違います。https:// で始まる URL を入れるか、空にしてください | 「動画の URL（あれば）」の欄を直すか、空にします |

### 10.2 レシピ・タイマー

| こんなとき | 対処 |
|---|---|
| 「保存できません。赤い字のところ（◯ か所）を直してください。」 | 赤い字の項目を直します（5.4） |
| 「⚠ 確かめてください（このままでも保存できます）」 | 目標量が合っているかを確かめます。合っていればそのまま保存できます |
| 音や読み上げが鳴らない | マナーモード（消音）を切る、音量を上げる、タイマー画面の「音」「読み上げ」がオンになっているかを確かめます |
| 豆の量が変えられない | 抽出中・一時停止中は変えられません。「RESET」で準備に戻してから変えます |
| 抽出中に画面が暗くなる | 「画面を暗くしない機能が使えません」と出る端末では、ときどき画面に触れてください |

### 10.3 ファイル・バックアップ

| 表示 | 対処 |
|---|---|
| CoffeeTimer のレシピのファイルではないため、読み込めませんでした | 選んだファイルが違います。「coffeetimer-recipe-」で始まるファイルを選びます |
| これはバックアップのファイルです。設定の「バックアップを読み込む」から読み込んでください | バックアップのファイルは「設定」タブから読み込みます（9.4） |
| これはレシピのファイルです。「＋ レシピを追加」→「ファイルから受け取る」から読み込んでください。何も変えていません | レシピのファイルは「レシピを追加」から読み込みます（9.2） |
| CoffeeTimer のバックアップのファイルではないため、読み込めませんでした。何も変えていません | 「coffeetimer-backup-」で始まるファイルを選びます |
| ファイルの中身が壊れているため、読み込めませんでした | ファイルが途中で切れたり、壊れたりしています。もう一度送ってもらうか、別のバックアップを使います |
| 新しい版の CoffeeTimer で作られたファイルのため、読み込めませんでした | ページを読み込み直して、アプリを新しくしてから試します |
| ファイルが大きすぎるため、読み込めませんでした | 選んだファイルが違う可能性があります。CoffeeTimer のファイルか確かめます |
| ファイルを開けませんでした | もう一度ファイルを選びます |

### 10.4 データ

| 表示・こんなとき | 対処 |
|---|---|
| レシピや記録が消えた | iPhone の Safari は、7日間開かないとデータを消すことがあります。書き出しておいたバックアップがあれば読み込みます（9.4）。これからは「ホーム画面に追加」して使ってください |
| この端末に保存できませんでした。ブラウザのプライベートモードや設定で、保存が止められている可能性があります。… | プライベートモード（シークレットモード）を使っていないかを確かめ、普通のモードで開き直します |
| 保存していたデータが読めなかったため、空の状態で始めました。… | 保存していたデータが壊れていました。バックアップがあれば読み込みます |
| 別のスマホにレシピがない | データはスマホごとに別です。バックアップを書き出して、別のスマホで読み込みます（9.3・9.4） |

## 11. 用語集

| 用語 | 意味 |
|---|---|
| レシピ | 1つの淹れ方。豆の量・湯量などと、手順の並び |
| 手順 | タイマーで順に進む1つ1つの作業（例 蒸らし、2投目）。開始の時刻を持つ |
| 開始 | その手順が始まる時刻（抽出を始めてからの時間） |
| 豆の量 | 使うコーヒー豆の重さ（g） |
| 湯量 | 注ぐお湯の合計の重さ（ml ではなく g） |
| 比率 | 豆1に対する湯量（湯量 ÷ 豆の量。例 1:16.7） |
| 湯温 | お湯の温度（℃） |
| 挽き目 | 豆を挽く細かさ（極細挽き／細挽き／中細挽き／中挽き／粗挽き） |
| 器具 | 使うドリッパーなどの道具（例 V60、エアロプレス） |
| 目標量 | その手順の終わりに、スケール（はかり）の表示がいくつになっていればよいか。注いだ合計（例「120g まで」） |
| 注ぐ量 | その手順で注ぐ量（目標量 − 前の目標量。例「+60g」） |
| 注意 | 気をつける手順の印と、その文。タイマーでは赤で出す |
| 完成時刻・抽出時間 | 抽出が終わる時刻。一覧やタイマーでは「抽出時間」と出す |
| 経過時間 | START からの時間（一時停止していた時間は数えない） |
| お気に入り | 一覧の上に並べる印。☆（していない）／★（している） |
| 淹れた記録 | 実際に淹れたときの日時・豆の名前・評価・メモ |
| APIキー | AI（Gemini）を使うための、あなた専用の鍵となる文字列 |
| バックアップ | レシピ・記録・設定をまとめて保存したファイル |

- 重さはすべて g、温度は ℃
- 時刻・時間は「分:秒」（例 1:30）で出ます。入れるときは 1:30 のほか、秒だけ（90）でも入れられます

## 13. 今後の予定

次のことは、今の版ではできません。

- 別のスマホやパソコンとのデータの自動の同期（今はバックアップのファイルで移します）
- アプリの中での動画の再生、動画の場面へ飛ぶこと
- スマホの振動で知らせること
- インターネットにつながっていないときに開くこと
- 英語など日本語以外の画面表示
