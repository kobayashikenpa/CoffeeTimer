# CoffeeTimer 仕様書（第1版）

YouTube のコーヒーレシピ動画を AI で読み取り、手順どおりに進む **抽出タイマー** にする Web アプリ。

## 1. 概要

- YouTube の動画の URL を入れると、AI（Google Gemini）が動画を見聞きしてレシピ（豆の量・湯量・湯温・挽き目・手順）を読み取る
- 読み取った結果を確かめて直してから保存し、タイマーで手順どおりに淹れる
- 利用者：オーナーと、その家族・友人（AI やプログラムに詳しくない人も使う）
- 利用環境：スマートフォン（iPhone / Android）のブラウザ。ホーム画面に追加してアプリのように使える
- 公開先：GitHub Pages（`https://kobayashikenpa.github.io/CoffeeTimer/`）。サーバーは持たない
- データ（レシピ・記録・設定・APIキー）は、使う人の端末のブラウザの中にだけ保存する

## 2. 用語

| 用語 | 意味 |
|---|---|
| レシピ | 1つの淹れ方。基本情報（豆の量・湯量など）と手順の並び |
| 手順 | タイマーで順に進む1つ1つの作業（例：蒸らし、1投目）。開始の時刻を持つ |
| 豆の量 | 使うコーヒー豆の重さ（g） |
| 湯量 | 注ぐお湯の合計の重さ（g） |
| 比率 | 豆1に対する湯量。湯量 ÷ 豆の量（例：1:16.7） |
| 湯温 | お湯の温度（℃） |
| 挽き目 | 豆を挽く細かさ（極細挽き／細挽き／中細挽き／中挽き／粗挽き） |
| 目標量 | その手順の終わりに、スケール（はかり）の表示がいくつになっていればよいか（g）。注いだ合計 |
| 注ぐ量 | その手順で注ぐ量。目標量 − 前の目標量 |
| 完成時刻 | 抽出が終わる時刻（最後の手順が終わる時刻） |
| 淹れた記録 | 実際に淹れたときの豆の名前・評価・メモ |
| APIキー | AI（Gemini）を使うための、利用者ごとの鍵となる文字列 |

- 重さの単位はすべて **g**（湯量も ml ではなく g）
- 時刻は抽出開始からの経過で、表示は 分:秒（例 1:30）

## 3. 全体の流れ

```
① レシピを追加：YouTube の URL を入れる（うまくいかなければ説明欄の文章を貼り付ける）
      ↓ AI が読み取る
② 確認・編集：読み取った結果を動画と見比べて直す → 保存
      ↓
③ レシピ一覧：お気に入りが上に並ぶ
      ↓ タップ
④ タイマー：豆の量を変えれば湯量・目標量を計算し直す → START → 手順ごとに音と読み上げ
      ↓ 完成
⑤ 淹れた記録：豆の名前・評価・メモを残す
```

## 4. 画面の構成

画面の下に3つのタブを置く。

| タブ | 中身 |
|---|---|
| レシピ | レシピ一覧・追加・編集・タイマー |
| 記録 | 淹れた記録の一覧 |
| 設定 | APIキー、音と読み上げ、バックアップ、ホーム画面への追加の説明 |

- タイマー画面の間は、下のタブを隠して画面を広く使う

## 5. レシピ

### 5.1 レシピの中身

| 項目 | 必須 | 内容 |
|---|---|---|
| レシピ名 | ○ | 例：4:6メソッド |
| 作者 | | 動画のチャンネル名など |
| 動画の URL | | 読み取り元の YouTube の URL。確認画面・タイマー画面から動画を開ける |
| 器具 | | 例：V60、エアロプレス |
| 豆の量 | ○ | g。0 より大きい。小数第1位まで |
| 湯量 | ○ | g。0 より大きい整数 |
| 湯温 | | ℃。整数 |
| 挽き目 | | 極細挽き／細挽き／中細挽き／中挽き／粗挽き／未設定 |
| 説明 | | 1〜2文のひと言 |
| 完成時刻 | ○ | 秒。最後の手順の開始より後 |
| 手順 | ○ | 1つ以上。5.2 |
| お気に入り | | する／しない |

- 比率は保存せず、豆の量と湯量から表示のたびに計算する（小数第1位まで。例 1:16.7）

### 5.2 手順の中身

| 項目 | 必須 | 内容 |
|---|---|---|
| 開始 | ○ | 秒。最初の手順は 0。前の手順より後 |
| 手順名 | ○ | 短い名前（例：蒸らし、2投目） |
| 説明 | | やることの説明（例：中心から「の」の字を描くように注ぐ） |
| 目標量 | | g。お湯を注ぐ手順だけに入れる。注がない手順（待つ、プレスする など）は空 |
| 注意 | | 注意が要る手順かどうか（する／しない）と、注意の文（例：ゆっくり押す） |

- 手順の終わりは、次の手順の開始（最後の手順は完成時刻）
- 注ぐ量 ＝ その手順の目標量 − それより前で最後に目標量がある手順の目標量（無ければ 0）
- 読み上げる文は自動で作る：「手順名。目標量グラムまで注いでください。注意の文」（目標量・注意の文が無ければその部分を省く）

### 5.3 保存するときの確かめ

保存できない（エラー）：

- レシピ名・豆の量・湯量・完成時刻・手順名が空
- 最初の手順の開始が 0 でない、手順の開始が前の手順より後になっていない
- 完成時刻が最後の手順の開始以前

保存はできるが、目立つ注意を出す：

- 目標量が前の目標量より小さい
- 最後の目標量が湯量と違う（エアロプレスのように、あとから割り水をするレシピもあるため）

### 5.4 レシピ一覧

- お気に入りを上に、その中は新しく追加・編集した順
- 1件ごとに：レシピ名、器具、豆の量・湯量・比率、完成時刻（抽出時間）、お気に入りの ☆／★ ボタン
- 各レシピに「⋯」ボタンを置き、「編集」「人に渡す」「削除」を出す（ボタンは常に表示する。マウスを重ねたときだけ出す作りにしない）
- 削除は確認してから行う。そのレシピの淹れた記録は消さずに残す
- 最初はレシピ0件。空のときは「＋ レシピを追加」への案内を出す

## 6. レシピの追加（AI で読み取る）

### 6.1 入れ方

「＋ レシピを追加」から、次のどれかを選ぶ。

1. **YouTube の URL**（基本）：`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/shorts/…`、`m.youtube.com/…` を受け付ける。形が違えば、送る前にその場で知らせる
2. **文章を貼り付ける**（予備）：動画の説明欄やブログのレシピの文章。URL も一緒に入れてよい（動画の URL として保存する）
3. **ファイルから受け取る**：人から渡されたレシピのファイル（10.1）を読み込む

### 6.2 AI の読み取り

- Gemini API に、動画の URL（または文章）と、決まった形（JSON）で答えるよう指示を送る
- 使う AI のモデルは、動画を読める Gemini のうち速くて無料枠のあるもの（第1版では gemini-2.5-flash を想定。変わっても差し替えやすくする）
- 英語など日本語以外の動画も読み取り、**手順名・説明は日本語に訳す**
- 豆の量・湯量・湯温が「oz」「℉」などで出てくる場合は g・℃ に直す
- 動画にはっきり出てこない値は空にする（推測で埋めない）。ただし手順の開始の時刻は、動画の説明から分かる範囲で決める
- 読み取り中は「動画を読み取っています（1〜2分かかることがあります）」と表示し、「やめる」ボタンで中止できる
- 読み取れたら、そのまま保存せず **確認・編集画面（7章）** に進む

### 6.3 うまくいかないとき

| 状況 | 表示 |
|---|---|
| APIキーが未設定 | 「AI を使うには APIキーの設定が必要です」＋ 設定への案内 |
| キーが正しくない | 「APIキーが正しくないようです。設定を確かめてください」 |
| 無料枠の回数を超えた | 「AI の利用回数の上限に達しました。しばらく待ってから試してください」 |
| 動画を開けない（非公開・削除・年齢制限など） | 「この動画は読み取れませんでした。説明欄の文章を貼り付けて試してください」＋ 貼り付けへ切り替えるボタン |
| レシピが見つからない | 「この動画からコーヒーのレシピを見つけられませんでした」 |
| 通信できない | 「インターネットにつながっていないようです」 |
| 返答の形が壊れている | 「読み取りに失敗しました。もう一度試すか、文章の貼り付けを試してください」 |

- AI の返答は信用せず、形・値の範囲を確かめてから使う。直せないものは空にして確認画面で入れてもらう

### 6.4 APIキーの扱い

- 利用者が Google AI Studio で自分のキーを取り、設定画面で入れる（取り方は取扱説明書と設定画面で案内する）
- キーは、その端末のブラウザにだけ保存する。画面には「設定済み」とだけ出し、キーの文字は出さない
- 通信では URL に入れず、ヘッダーで渡す
- バックアップや人に渡すファイルには入れない
- 「キーを確かめる」ボタンで、キーが使えるかを試せる

## 7. 確認・編集画面

- AI で読み取った直後と、一覧の「編集」から開く。どちらも同じ画面
- 上に「AI の読み取りは間違えることがあります。動画と見比べて確かめてください」と出す（AI で読み取った直後だけ）
- 「動画を開く」ボタンで、YouTube を別の画面で開ける（動画の URL があるとき）
- 5.1 の基本情報と 5.2 の手順を入力・修正できる
  - 時刻は 分:秒 で入れられる（例 1:30。秒だけの 90 も可）
  - 手順の追加・削除・並べ替え（開始の時刻で自動的に並ぶ）
- 5.3 のエラーがあれば保存できず、どこが悪いかをその項目のそばに出す
- 「保存」で一覧に戻る。「やめる」で保存せずに戻る（入力があれば確認する）

## 8. タイマー

### 8.1 画面

- 上：レシピ名、動画を開くボタン、「編集」ボタン
- 豆の量（変えられる）・湯量・比率・湯温・挽き目・抽出時間
- まん中：経過時間（大きく）と、進み具合を示す輪。輪には手順の切り替わりの目印
- 今の手順：手順名、**目標量（いちばん大きく。例「120g まで」）**、注ぐ量（小さく。例「+60g」）、説明、注意（赤）
- 次の手順：手順名と、始まるまでの残り秒数
- 手順の一覧：終わった／今／これから が分かる表示。各手順に開始の時刻と目標量
- ボタン：START（一時停止・再開を兼ねる）、RESET
- 音と読み上げの ON／OFF をその場で切り替えられる（設定の初期値を使う）

### 8.2 豆の量を変える

- タイマー画面で、始める前に豆の量を変えられる（− ＋ ボタンと直接入力。0.5g 刻み、直接入力は小数第1位まで）
- 変えると、湯量と各手順の目標量を豆の量に比例して計算し直す。**時間は変えない**
  - 新しい値 ＝ 元の値 × 新しい豆の量 ÷ 元の豆の量 を、**1g 単位に四捨五入**
  - 例：豆 15g・湯量 250g → 豆 20g にすると 湯量 333g（250 × 20 ÷ 15 = 333.3…）
  - 注ぐ量は、計算し直した目標量どうしの差で出す（丸めた後の値で引く）
- 変えた豆の量はそのときだけ使い、レシピ自体は変えない（「元に戻す」で元の豆の量へ）
- 抽出中・一時停止中は変えられない

### 8.3 進み方

- 状態：準備 → 抽出中 ⇄ 一時停止 → 完成
- 経過時間は **START を押した時刻からの実時間** で数える（画面の更新が遅れても、時間はずれない）。一時停止していた時間は数えない
- 手順が切り替わった瞬間に、音を鳴らし、読み上げる（1回だけ）
  - 普通の手順：短い音1回。注意の手順：低めの音1回。完成：音3回＋「抽出完了です」と読み上げ
  - 抽出開始（0秒）の手順も、START と同時に鳴らして読み上げる
- 手順をタップすると、その手順の開始の時刻に飛ぶ（抽出中なら続けて進む、一時停止中なら一時停止のまま、準備中ならそこから始める）
- 完成時刻で止まり、「抽出完了」を表示して「記録をつける」ボタンを出す
- RESET で準備に戻る（確認は出さない）
- スマホが画面を消したり、別のアプリに切り替えたりしても、戻ったときには実時間に合わせた表示に戻る（その間の音・読み上げは鳴らないことがある）

### 8.4 画面を暗くしない

- 抽出中と一時停止中は、スマホの画面が自動で暗くなったり消えたりしないようにする（Screen Wake Lock。使えない端末では、その旨を小さく表示する）
- タイマー画面を離れたら元に戻す

### 8.5 音と読み上げ

- 音はアプリの中で作る（音声ファイルは使わない）
- 読み上げは端末の日本語の読み上げ機能を使う
- iPhone で鳴るよう、START を押したときに音と読み上げの準備をする
- マナーモード（消音）のときは鳴らないことがある（取扱説明書で案内する）

## 9. 淹れた記録

### 9.1 記録の中身

| 項目 | 入れ方 |
|---|---|
| 日時 | 自動（記録をつけたとき）。直せる |
| レシピ | 自動（レシピ名も一緒に残す。レシピを消しても名前は残る） |
| 豆の量・湯量 | 自動（そのとき使った値。8.2 で変えていればその値） |
| 豆の名前・お店 | 手入力（任意） |
| 評価 | ★1〜5（任意） |
| メモ | 自由記入（任意） |

### 9.2 つけ方と見方

- タイマーの完成後に出る「記録をつける」から入れる
- 記録タブ：新しい順に一覧。レシピで絞り込める。タップで編集、削除（確認あり）

## 10. 受け渡しとバックアップ

### 10.1 レシピを人に渡す

- 一覧の「⋯」→「人に渡す」で、そのレシピ1件をファイル（`.json`）にする
- スマホの共有機能（LINE・メールなど）で送る。共有機能が使えない端末ではファイルとして保存する
- ファイルには記録・APIキーを入れない。お気に入りの印も入れない
- 受け取る側は「＋ レシピを追加」→「ファイルから受け取る」で読み込み、確認・編集画面を通して保存する

### 10.2 バックアップ

- 設定の「バックアップを書き出す」で、レシピ・記録・設定（APIキーを除く）をまとめて1つのファイルにする
- 「バックアップを読み込む」で戻す。今のデータに **足す**（同じレシピ・記録があれば、読み込んだほうで上書きする。上書きの前に件数を示して確認する）
- 読み込むファイルの形が違う・壊れているときは、何も変えずにエラーを出す

### 10.3 データが消えることへの備え

- 設定画面と取扱説明書で、次を案内する
  - iPhone の Safari は、7日間そのサイトを開かないと保存したデータを消すことがある。「ホーム画面に追加」して使うと消えにくい
  - ときどきバックアップを書き出しておく
- ホーム画面に追加したとき、アプリ名「CoffeeTimer」とアイコンが出るようにする

## 11. 設定

| 項目 | 初期値 | 内容 |
|---|---|---|
| APIキー | 未設定 | 入れる・消す・確かめる。取り方の案内（Google AI Studio へのリンク） |
| 音 | ON | タイマーの音の初期値 |
| 読み上げ | ON | タイマーの読み上げの初期値 |
| バックアップ | － | 書き出す・読み込む（10.2） |
| ホーム画面への追加 | － | iPhone・Android それぞれの手順の説明 |

## 12. 見た目

- 暗い配色（コーヒーらしい焦げ茶とアンバー）を基本とする。スマホが明るい表示の設定なら、明るい配色にする
- 幅 375px 前後のスマホで横スクロールしない。ボタンは指で押しやすい大きさ（高さ 44px 以上）
- タイマーの経過時間と目標量は、スマホを置いて少し離れても読める大きさ

## 13. 第1版で作らないもの

- アカウント・端末間の同期（データは端末ごと）
- アプリの中での動画の再生、動画の場面へ飛ぶリンク
- スマホの振動
- ネットにつながっていないときに開くこと（オフライン対応）
- 英語など日本語以外の画面表示
