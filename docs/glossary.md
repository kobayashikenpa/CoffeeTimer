# CoffeeTimer 画面の用語

画面・取扱説明書・読み上げで使う言葉をそろえるための一覧。仕様書 `docs/spec.md`（第1版）の「2. 用語」と、画面に出す言葉をまとめる。
仕様書で決まっていない文言には **（暫定）** を付ける。

## 1. コーヒーとレシピの言葉（仕様書 2章）

| 用語 | 意味 | 表示の例 |
|---|---|---|
| レシピ | 1つの淹れ方。基本情報（豆の量・湯量など）と手順の並び | 4:6メソッド |
| 手順 | タイマーで順に進む1つ1つの作業。開始の時刻を持つ | 蒸らし、2投目 |
| 開始 | その手順が始まる時刻（抽出開始からの経過） | 0:45 |
| 豆の量 | 使うコーヒー豆の重さ | 15g |
| 湯量 | 注ぐお湯の合計の重さ（ml ではなく g） | 250g |
| 比率 | 豆1に対する湯量（湯量 ÷ 豆の量、小数第1位まで） | 1:16.7 |
| 湯温 | お湯の温度 | 92℃ |
| 挽き目 | 豆を挽く細かさ。極細挽き／細挽き／中細挽き／中挽き／粗挽き／未設定 | 中細挽き |
| 器具 | 使うドリッパーなどの道具 | V60、エアロプレス |
| 作者 | レシピを作った人。動画のチャンネル名など | |
| 目標量 | その手順の終わりに、スケール（はかり）の表示がいくつになっていればよいか。注いだ合計 | 120g まで |
| 注ぐ量 | その手順で注ぐ量（目標量 − 前の目標量） | +60g |
| 注意 | 気をつける手順の印と、その文。タイマーでは赤で出す | ゆっくり押す |
| 完成時刻 | 抽出が終わる時刻（最後の手順が終わる時刻） | 3:30 |
| 抽出時間 | 一覧・タイマーで完成時刻を「かかる時間」として出すときの呼び方 | 抽出時間 3:30 |
| 経過時間 | START からの時間（一時停止していた時間は数えない） | 1:05 |
| お気に入り | 一覧の上に並べる印。☆（していない）／★（している） | ★ |
| 淹れた記録 | 実際に淹れたときの日時・豆の名前・評価・メモ | |
| 豆の名前・お店 | 淹れた記録に残す、使った豆の名前と買ったお店 | エチオピア（○○珈琲） |
| 評価 | 淹れた記録の ★1〜5 | ★★★★ |
| APIキー | AI（Gemini）を使うための、利用者ごとの鍵となる文字列 | 設定済み |

- 重さはすべて **g**、温度は **℃**
- 時刻・時間の表示は **分:秒**（例 1:30）。入力は 1:30 のほか秒だけ（90）でもよい

## 2. タブと画面の名前

| 呼び方 | 何の画面か |
|---|---|
| 「レシピ」タブ | レシピ一覧・追加・編集・タイマー |
| 「記録」タブ | 淹れた記録の一覧 |
| 「設定」タブ | APIキー、音と読み上げ、バックアップ、ホーム画面への追加の説明 |
| レシピ一覧 | レシピが並ぶ画面（お気に入りが上） |
| レシピの追加 | 「＋ レシピを追加」から開く、入れ方を選ぶ画面 |
| 確認・編集画面 | 読み取ったレシピや保存したレシピを確かめて直す画面。画面の見出しは、新しいレシピ（AI の読み取り・手で入れる・受け取ったファイル）のときは「レシピを作る」、保存したレシピを直すときは「レシピを直す」（暫定） |
| タイマー画面 | 手順どおりに進むタイマー |
| 記録をつける画面 | 完成後に淹れた記録を入れる画面。画面の見出しは「淹れた記録をつける」（暫定の呼び方） |
| 記録を直す画面 | 記録タブで記録を押して開く画面。見出しは「記録を直す」（暫定） |

## 3. ボタン・操作の言葉

| 文言 | 場所 | 働き |
|---|---|---|
| ＋ レシピを追加 | レシピ一覧 | レシピの追加を始める |
| YouTube の URL | レシピの追加 | 動画の URL から AI で読み取る |
| 文章を貼り付ける | レシピの追加・エラー表示 | 説明欄やブログの文章から AI で読み取る |
| ファイルから受け取る | レシピの追加 | 人から渡されたレシピのファイルを読み込む |
| 手で入れる | レシピの追加 | 空の確認・編集画面を開く（暫定。tasks.md 未決事項 1） |
| やめる | 読み取り中・確認・編集画面 | 読み取りを中止する／保存せずに戻る |
| 保存 | 確認・編集画面 | 確かめて保存し、一覧に戻る |
| 動画を開く | 確認・編集画面・タイマー画面 | YouTube を別の画面で開く |
| ＋ 手順を追加 | 確認・編集画面 | 手順を1つ増やす |
| ☆／★ | レシピ一覧 | お気に入りにする／外す |
| ⋯ | レシピ一覧 | 「編集」「人に渡す」「削除」を出す |
| 編集 | 「⋯」・タイマー画面 | 確認・編集画面を開く |
| 人に渡す | 「⋯」 | そのレシピをファイルにして、LINE・メールなどで送る |
| 削除 | 「⋯」・記録 | 確認してから消す |
| − ／ ＋ | タイマー画面の豆の量 | 豆の量を 0.5g ずつ変える |
| 元に戻す | タイマー画面 | 変えた豆の量をレシピの値に戻す |
| START | タイマー画面 | 抽出を始める。抽出中は一時停止、一時停止中は再開 |
| RESET | タイマー画面 | 準備に戻す（確認なし） |
| 記録をつける | タイマー画面（完成後） | 淹れた記録を入れる |
| キーを確かめる | 設定 | APIキーが使えるかを試す |
| ファイルを選ぶ（暫定） | レシピの追加（ファイルから受け取る） | 受け取ったレシピのファイルを選ぶ |
| ★1〜★5／評価を消す（暫定） | 記録をつける画面 | 評価をつける／なしにする（同じ★をもう一度押しても消える） |
| レシピで絞り込む（暫定） | 記録タブ | そのレシピの記録だけを出す。消したレシピは「（削除したレシピ・n件）」と出す |
| この記録を削除（暫定） | 記録を直す画面 | 確認してから記録を消す |
| 上書きして読み込む（暫定） | バックアップの読み込みの確認 | 同じレシピ・記録があるときの確認のボタン（無いときは「読み込む」） |
| バックアップを書き出す | 設定 | レシピ・記録・設定を1つのファイルにする |
| バックアップを読み込む | 設定 | 書き出したファイルから、今のデータに足す |

## 4. タイマーの状態と表示

| 文言 | 意味 |
|---|---|
| 準備 | START を押す前。豆の量を変えられる |
| 抽出中 | 時間が進んでいる |
| 一時停止 | 止めている。再開すると続きから進む |
| 完成 | 完成時刻に達した。「抽出完了」と出す |
| 抽出完了 | 完成したときの表示。読み上げは「抽出完了です」 |
| 今の手順 | いま行う手順（目標量をいちばん大きく出す） |
| 次の手順 | 次に行う手順と、始まるまでの残り秒数（例「あと 12 秒」（暫定）） |
| 音／読み上げ | タイマー画面での ON／OFF の切り替え |
| 読み上げの文 | 「手順名。目標量グラムまで注いでください。注意の文」（無い部分は省く） |
| 画面を暗くしない機能が使えません（暫定） | Wake Lock が使えない端末での小さな表示 |

## 5. 画面に出す案内・エラーの文（仕様書 6.3・7 章）

| 場面 | 文 |
|---|---|
| 読み取り中 | 動画を読み取っています（1〜2分かかることがあります） |
| 読み取った直後の確認・編集画面 | AI の読み取りは間違えることがあります。動画と見比べて確かめてください |
| APIキーが未設定 | AI を使うには APIキーの設定が必要です |
| キーが正しくない | APIキーが正しくないようです。設定を確かめてください |
| 無料枠の回数を超えた | AI の利用回数の上限に達しました。しばらく待ってから試してください |
| 動画を開けない | この動画は読み取れませんでした。説明欄の文章を貼り付けて試してください |
| レシピが見つからない | この動画からコーヒーのレシピを見つけられませんでした |
| 通信できない | インターネットにつながっていないようです |
| 返答の形が壊れている | 読み取りに失敗しました。もう一度試すか、文章の貼り付けを試してください |
| レシピが0件 | 「＋ レシピを追加」への案内（文は画面の作業で決める） |

## 6. 使わない言葉（言い換え）

画面では、詳しくない人にも分かるよう次のように言い換える。

| 使わない | 使う |
|---|---|
| ステップ | 手順 |
| 投数だけの呼び方（例「2」） | 2投目 |
| ml | g |
| エクスポート | 書き出す |
| インポート | 読み込む |
| シェア・共有する（ボタン名として） | 人に渡す |
| 総湯量・トータル | 湯量 |
| 累計・累積 | 目標量 |
| ブリュー・抽出記録 | 淹れた記録 |
| トークン・認証情報 | APIキー |
| エラーコード・ステータス番号 | 出さない（5章の文にする） |
